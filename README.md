# КонспектХаб (NoteSwap)

## Описание проекта
IT-продукт для студентов, позволяющий быстро находить и обмениваться конспектами учебных материалов.

## Проблема
Студенты пропускают занятия или не успевают записать материал, и у них нет быстрого способа получить качественные конспекты от одногруппников.

## Целевая аудитория
Студенты колледжа (преимущественно 1–3 курс), которые пропускают пары по болезни или другим причинам.

## Решение
Простое консольное приложение на Python, где можно оставить запрос на нужный конспект или предложить свой материал другим.

## Главные функции MVP
1. Создать запрос на конспект (предмет, тема, дата)
2. Просмотреть ленту всех активных запросов
3. Оставить свой контакт (ник в Telegram) под запросом

## Технологии
- Python 3.x
- JSON для хранения данных

## Как запустить
1. Убедитесь, что установлен Python 3.7 или выше
2. Скачайте файл `src/main.py`
3. Выполните команду: `python main.py`

## Ограничения текущей версии (MVP)
- Нет загрузки файлов (только текстовые запросы)
- Нет регистрации пользователей
- Нет модерации контента
- Данные хранятся локально в JSON-файле
