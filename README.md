# 🎓 КонспектХаб (NoteSwap) v1.0

## Описание проекта
IT-продукт для студентов, позволяющий быстро находить и обмениваться конспектами учебных материалов внутри колледжа.

## Проблема
Студенты пропускают занятия или не успевают записать материал, и у них нет быстрого способа получить качественные конспекты от одногруппников без поиска по десяткам чатов.

## Целевая аудитория
Студенты колледжа (1–3 курс), пропускающие пары по болезни или другим причинам.

## Работающие функции MVP (v1.0)
1. **Создание запроса:** Ввод предмета, темы, даты и типа (Ищу/Предлагаю) с защитой от пустых полей.
2. **Просмотр ленты:** Отображение всех активных запросов в удобном формате.
3. **Обмен контактами:** Возможность оставить свой Telegram или другой контакт под конкретным запросом.

## Технологии
- Python 3.x (консольное приложение)
- Git / GitHub (контроль версий)

## 🚀 Как запустить
1. Убедитесь, что на компьютере установлен Python 3.7 или выше.
2. Скачайте файл `src/main.py` из этого репозитория.
3. Откройте терминал (командную строку) в папке с файлом.
4. Выполните команду: `python main.py`
5. Следуйте инструкциям в меню (вводите цифры 1, 2, 3 или 0).

## ⚠️ Ограничения текущей версии
- Данные хранятся только в оперативной памяти (исчезают после закрытия программы). Сохранение в JSON запланировано в v2.0.
- Нет графического интерфейса (только консоль).
- Нет системы регистрации и модерации.
