#  Трекер ошибок проекта "КонспектХаб"

## Баг-репорт №1
**Название дефекта:** Программа создаёт запрос с пустым полем "Предмет"
**Шаги воспроизведения:**
1. Запустить `python src/main.py`
2. Выбрать пункт меню `1` (Создать запрос)
3. В поле "Предмет" нажать Enter, не вводя текст.
4. Заполнить остальные поля и подтвердить создание.
**Ожидаемый результат:** Программа выводит ошибку "Поле обязательно для заполнения" и не создаёт запрос.
**Фактический результат:** Запрос успешно создаётся с пустым названием предмета.
**Серьёзность / приоритет:** Высокая / Высокий
**Ответственный:** Разработчик
**Результат повторной проверки:** Исправлено

## Баг-репорт №2
**Название дефекта:** Программа принимает некорректный формат даты
**Шаги воспроизведения:**
1. Запустить `python src/main.py`
2. Выбрать пункт меню `1`.
3. В поле "Дата" ввести `32.15.2024` или `абв`.
4. Подтвердить создание.
**Ожидаемый результат:** Программа просит ввести дату в формате ДД.ММ.ГГГГ.
**Фактический результат:** Программа принимает любую строку как валидную дату.
**Серьёзность / приоритет:** Средняя / Средний
**Ответственный:** Разработчик
**Результат повторной проверки:** _Ожидает исправления_

---

## Баг-репорт №3
**Название дефекта:** Программа принимает пробелы в качестве валидного названия предмета
**Шаги воспроизведения:**
1. Запустить `python src/main.py`
2. Выбрать пункт меню `1`.
3. В поле "Предмет" нажать пробел 3 раза и нажать Enter.
**Ожидаемый результат:** Программа должна считать это пустым полем и выдать ошибку.
**Фактический результат:** Запрос создаётся с названием "   " (три пробела).
**Серьёзность / приоритет:** Низкая / Низкий
**Ответственный:** Разработчик
**Результат повторной проверки:** Исправлено
